# Evraziya Portal

B2B-портал для группы компаний ЕВРАЗИЯ — оптовая дистрибуция итальянских изделий из кожи и аксессуаров.

## Стек технологий

| Категория            | Технология                            |
| -------------------- | ------------------------------------- |
| Framework            | Next.js 16 (App Router) + React 19    |
| Язык                 | TypeScript 5 (strict mode)            |
| База данных / Auth   | Supabase (PostgreSQL, Auth, Realtime) |
| Стили                | Tailwind CSS 4 + shadcn/ui + Radix UI |
| Серверное состояние  | TanStack React Query                  |
| Клиентское состояние | Zustand                               |
| URL-состояние        | nuqs                                  |
| Формы                | React Hook Form + Zod                 |
| Иконки               | Lucide React                          |
| Анимации             | Framer Motion                         |
| Пакетный менеджер    | yarn                                  |

## Быстрый старт

```bash
# Установка зависимостей
yarn install

# Копирование переменных окружения
```

## Разработка с Claude Code (Wave-Per-Session)

Проект настроен для структурированной разработки с Claude Code по методологии [Wave-Per-Session](../Wave-Per-Session.md).

### Что настроено

- **CLAUDE.md** — инструкции для Claude: команды сборки, конвенции кода, структура, лог ошибок
- **`.claude/settings.json`** — предварительные разрешения для стандартных операций (build, lint, git)
- **Wave-скиллы** — `/wave-start` и `/wave-verify` для выполнения и проверки волн
- **Скиллы стека** — специализированные команды для технологий проекта

### Горячие клавиши

| Клавиша     | Действие                                   |
| ----------- | ------------------------------------------ |
| `Esc`       | Остановить Claude                          |
| `Esc Esc`   | Меню отката (откат кода + разговора)       |
| `Ctrl+B`    | Фоновый режим для текущего агента/команды  |
| `Ctrl+G`    | Открыть промпт в `$EDITOR`                 |
| `Ctrl+O`    | Показать полный транскрипт мышления Claude |
| `Ctrl+T`    | Переключить видимость списка задач         |
| `Alt+T`     | Включить/выключить мышление                |
| `Shift+Tab` | Переключение режимов (Edit / Plan / Auto)  |

### Основные команды

| Команда             | Описание                                          |
| ------------------- | ------------------------------------------------- |
| `/wave-start`       | Выполнить следующую волну задач                   |
| `/wave-verify`      | Build + lint + ревью + фиксы                      |
| `/add-page`         | Создать новую страницу Next.js App Router         |
| `/add-api-route`    | Создать новый API-маршрут с Supabase              |
| `/add-shadcn`       | Добавить/настроить shadcn/ui компонент            |
| `/supabase-migrate` | Создать миграцию Supabase + обновить типы         |
| `/add-feature`      | Создать полную фичу (страница + API + компоненты) |
| `/plan`             | Режим планирования (без изменения файлов)         |
| `/compact "focus"`  | Сжать контекст с приоритетом                      |
| `/rewind`           | Откатить код + разговор                           |
| `/context`          | Показать использование контекстного окна          |
| `/tasks`            | Показать список задач                             |
| `/rename <name>`    | Дать имя текущей сессии для лёгкого возобновления |
| `/stats`            | Статистика использования (`r` для смены периода)  |
| `/debug`            | Отладка текущей сессии                            |
| `/doctor`           | Диагностика конфигурации и разрешений             |

### Управление сессиями

```bash
claude -c                       # Продолжить последнюю сессию (текущая папка)
claude --resume                 # Просмотреть все сессии
claude --resume "feature-auth"  # Возобновить по имени (если использовали /rename)
claude --from-pr 123            # Возобновить сессию, привязанную к PR
claude --from-pr https://...    # Возобновить по URL PR
```

### Размер фичи и подход

| Размер  | Задачи | Подход                                                     |
| ------- | ------ | ---------------------------------------------------------- |
| Trivial | 1-2    | Просто попросите Claude. Волны не нужны.                   |
| Small   | 3-5    | **Lite** — один промпт, выполнение в одной сессии.         |
| Medium  | 6-15   | **Standard** — планируем волны, одна сессия на волну.      |
| Large   | 16+    | **Full** — волны + worktrees или fan-out для параллелизма. |

### Рабочий процесс: Standard mode (6-15 задач)

**PLAN:**

```bash
export CLAUDE_CODE_TASK_LIST_ID="evraziya-portal-<feature>"
claude
```

Промпт для планирования:

```
Мне нужно реализовать [ОПИСАНИЕ ФИЧИ].

Прочитай кодовую базу, чтобы понять существующие паттерны.
Задай уточняющие вопросы перед тем, как продолжить.

Затем:
1. Создай план реализации с файлами, зависимостями и критериями приёмки
2. Построй граф зависимостей
3. Рассчитай волны выполнения
4. Создай Tasks для каждого пункта
5. Сохрани человекочитаемый план в tasks.md
```

Проверьте план, закоммитьте `tasks.md`, выйдите из сессии.

**EXECUTE (повторять для каждой волны):**

```bash
claude                  # новая сессия
```

```
/wave-start             # выполнить волну
/wave-verify            # проверить
```

```bash
git add -A && git commit -m "feat: wave N — описание"
```

Выйти, повторить для следующей волны.

Дополнительные инструкции для `/wave-start`:

```
/wave-start Skip TASK-003 for now. TASK-005 is complex — have its sub-agent read the API docs first.
```

**FINALIZE:**

```
Все волны завершены. Запусти полную сборку и тесты.
Проверь все изменения vs main. Создай PR с описанием,
разбивкой по волнам и заметками для тестирования.
```

Обновите Mistakes Log в CLAUDE.md:

```
Проверь git log этого feature branch. Были ли fixup-коммиты,
где начальная реализация была ошибочной? Добавь каждый паттерн
в Mistakes Log в CLAUDE.md.
```

### Рабочий процесс: Lite mode (3-5 задач)

```bash
export CLAUDE_CODE_TASK_LIST_ID="evraziya-portal-<small-task>"
claude
```

```
Мне нужно реализовать [ФИЧА].

Прочитай кодовую базу, спланируй задачи и выполни их с параллельными
суб-агентами где возможно. Запусти build и тесты после каждой задачи.
Когда всё пройдёт, подведи итоги.
```

### Дерево решений при проблемах

```
Что-то пошло не так
├── Плохой код, ещё в сессии → Esc Esc → /rewind
├── Контекст заполнен → /compact "focus on X" → не помогло? → exit, claude -c
├── Build падает после волны → "fix integration only, don't refactor"
├── Нужно переключиться → Ctrl+B для фонового режима
└── Полностью запутался → exit, новая сессия, перечитать задачи
```

### Продвинутые возможности (справочно)

Подробности в [Wave-Per-Session.md](../Wave-Per-Session.md), Part D:

- **LSP plugins** — семантическая навигация по коду (900x быстрее grep)
- **Custom agents** (`.claude/agents/`) — ограничение инструментов, системные промпты
- **Hooks** — автоматические quality gates (SessionEnd, PreToolUse, Stop)
- **`.claude/rules/`** — персистентные поведенческие правила
- **Background agents** — `Ctrl+B` или `&` префикс для фоновых задач
- **Git worktrees** — параллельная работа в изолированных деревьях
- **Headless fan-out** — массовый запуск для 10+ повторяющихся задач
- **Teleport** — выгрузка задач в облако (claude.ai/code)
- **TDD Wave Pattern** — сначала тесты (Session A), потом реализация (Session B)
- **`--agent` flag** — переопределение агента для конкретной сессии

## Git-стратегия

Проект использует **GitHub Flow** с ветками:

| Префикс    | Назначение                 | Базовая ветка |
| ---------- | -------------------------- | ------------- |
| `feature/` | Новые фичи                 | develop       |
| `fix/`     | Баг-фиксы                  | develop       |
| `hotfix/`  | Срочные фиксы продакшна    | main          |
| `chore/`   | Рефакторинг, инфра, конфиг | develop       |

Каждая фича разрабатывается в отдельной ветке с PR в целевую ветку.

## Code Style

- **Одинарные кавычки** для строк
- **Trailing commas** везде
- **100 символов** ширина строки
- Конфигурация: `.prettierrc`, `eslint.config.mjs`
